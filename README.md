# Security-Log-Fundamentals
study common security logs and identify useful field such as  timestamp , user , source IP and event type.


## Objective
To understand security logs and identify important fields such as timestamps, usernames, source IP addresses, event types, and login results.

## Tools Used
- JSLinux
- Linux terminal

## Project Description
This project demonstrates basic security log analysis using sample authentication records in a Linux environment. The logs contain successful and failed login attempts.

## Practical Activities
- Created a synthetic authentication log file.
- Viewed log entries using Linux commands.
- Filtered failed login attempts using `grep`.
- Counted failed login attempts.
- Identified timestamps, usernames, source IP addresses, event types, and results.

## Findings
The sample logs contain three failed login attempts for the admin account from the same source IP address. This pattern may require further investigation.

## Learning Outcome
Learned how to read, filter, and analyse basic security logs using Linux command-line tools.

## Conclusion
Security logs help monitor system activities, investigate suspicious events, and support incident detection.
